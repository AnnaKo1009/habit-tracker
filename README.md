Habit Flow — это веб-приложение, созданное для контроля личных привычек и целей.

Возможности для пользователя:
  -- Создание привычек с разной периодичностью (ежедневно, еженедельно, с интервалом)
  -- Использование календаря для выбора даты и просмотра привычек
  -- Отметка выполнения одним кликом
  -- Статистика — серии, прогресс, графики
  -- Тёмная и светлая тема
  -- Адаптивность — удобно на любых устройствах

Технический стек
  Фронтенд:
React — современная библиотека для UI
TypeScript — строгая типизация
Redux Toolkit — управление состоянием
React Router — навигация
Axios — HTTP-запросы с перехватчиками
Vite — быстрая сборка
CSS Modules — изолированные стили

  Бэкенд:
NestJS — модульный серверный фреймворк
PostgreSQL — надёжная база данных
Prisma ORM — работа с БД через TypeScript
JWT — безопасная аутентификация
bcrypt — хеширование паролей
